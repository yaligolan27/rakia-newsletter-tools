תשתית להפקת הניוזלטר השבועי (חמישי 17:00 לפי האפיון). **גרסה 2 (17.8.2026, לפי משוב מאיה): עמוד מגזין רספונסיבי במסך מלא** — לא עוד "כרטיס מייל" צר: תמונות אמיתיות מכל כתבה, פילטר קטגוריות, הרחבה גלויה תמיד (מאיה ביטלה את כפתור "קרא עוד"), מקטע ספוטלייט לאירוע מרכזי, סרטונים, אנימציות גלילה. שפת העיצוב של טמפלט Claude Design נשמרה (Almoni, נייבי, גרדיאנט).

## אתר ציבורי (GitHub + Vercel)

- `site/` — ריפו גיט עצמאי של האתר הסטטי: `index.html` (הגיליון האחרון), `NNN/` (ארכיון לכל גיליון), `archive/` (רשימת גיליונות), `og*.jpg` (תמונות preview לוואטסאפ, נבנות עם bidi ידני כי אין raqm).
- `build_site.py` — בונה את site/ מכל הגיליונות שב-content/+output/. `site_config.json` — base_url (לעדכן לכתובת Vercel האמיתית אחרי החיבור!).
- `publish_site.py "issue NNN"` — **הפרסום לאוויר**: build_site → commit → push → Vercel מפרסם אוטומטית. **מ-4.10.2026 הרוטינה השבועית מפרסמת אוטומטית, בלי אישור ידני** (החלטת המשתמש).
- זרימה: הרוטינה של יום ראשון מפיקה גיליון → מעדכנת את ה-Artifact → מריצה `publish_site.py` → האתר מתעדכן. הקישור הקבוע https://rakia-weekly.vercel.app מציג תמיד את הגיליון האחרון, וכל גיליון נשמר בארכיון ב-`/YYYY-MM-DD/` וב-`/archive/`.
- סאבדומיין עתידי: newsletter.rakiamission.com — רשומת CNAME אצל מנהל הדומיין אל Vercel, ואז לעדכן base_url ולהריץ publish.

## רוטינה שבועית

### החלטות עריכה קבועות (משוב 18.8.2026)
- אין מדור "בקצרה" — או כתבה מלאה או כלום.
- מדור ההזדמנויות נקרא **"הזדמנויות חמות"**: הזדמנות נשארת עד שהיא נסגרת (לא רק שבוע). 4 בולטות + השאר מאחורי כפתור "עוד הזדמנויות".
- סדר החדשות לפי עניין: תעשייה ישראלית, עסקאות גדולות, SpaceX וסיפורים מסקרנים קודם; מינויים/בירוקרטיה בסוף. לוודא נוכחות SpaceX.
- דבר המערכת עם היפרלינקים בתוך המשפטים (editorial.segments עם url).
- ספוטלייט = במה לאירוע/יוזמה של רקיע (placeholder עם תג "טיוטה" עד שמגיע תוכן). ההאקתון של NASA Space Apps נשאר שורת אירוע בלוח.
- לוגו מנהלת החלל: `assets/logo-minhelet.png` הוחלף בגרסה שקופה (המקור נשמר כ-`logo-minhelet-orig.png`).

## הפקת גיליון (שבועי)

1. **איסוף ואימות תוכן** — להריץ ב-Claude Code את הוורקפלואו (סקריפט שמור בסשנים קודמים; או לבקש: "הפק את הניוזלטר השבועי של רקיע לשבוע X–Y"). מבנה הצוות:
   - 8 סוכני איסוף לפי ביט: Payload, SpaceNews, מדיניות (Space Foundation/Breaking Defense), שיגורים (+לוג שיגורים מלא לשבוע), גיוסים וחוזים, ישראל-במקורות-בינ"ל, הזדמנויות (קולות קוראים/וובינרים/האקסלרטורים), אירועים קרובים.
   - 4 מאמתים אדברסריים (חדשות א'/ב', הזדמנויות — כולל בדיקה שהדדליין עתידי, אירועים).
   - עורך: בחירה לפי האפיון (ליד + 6–9 אייטמים בקטגוריות + 3 בקצרה + 2+2 הזדמנויות + 3 אירועים + 3 סטטיסטיקות מחושבות מהחומר בלבד) וכתיבת עברית.
   - מבקר: נאמנות למקורות + איכות עברית.
2. **תמונות** — `python fetch_article_images.py <map.json>` (מפה slug→URL של כתבה; מוריד og:image). תמבני יוטיוב: `i.ytimg.com/vi/<id>/maxresdefault.jpg`. כתבה חסומה (403/paywall) → תמונת מותג `brand:img-*.png`.
3. **שמירת התוכן** — `content/issue_NNN_v2.json` (העתיקו מבנה מגיליון קיים; כולל spotlight/videos אופציונליים).
4. **בנייה**:
   ```
   python build_newsletter.py content/issue_NNN_v2.json
   ```
   הפלט נכתב ל-`output/` ועותק `ניוזלטר_שבועי_NNN.html` לתיקיית הפרויקט.
5. **תצוגה מקדימה** — שרת מקומי ב-`.claude/launch.json` (`newsletter-preview`, פורט 8766).
6. **פרסום** — Artifact מתוך `output/newsletter_NNN_artifact.html` (אותו URL בכל שבוע = עדכון הגיליון).

## מדור "השיגורים הבאים" (מ-23.9.2026)

- מפתח `launches` ב-JSON: `title`, `intro`, `items[]` עם `id`/`net`/`status` מ-Launch Library 2, `title`/`payload`/`meta` בעברית, `url` לעמוד המעקב ב-Space Launch Schedule (`/launch/<slug>/`), `featured` לסטארשיפ/שיגור מעניין, `scope: "ישראל"` למטען ישראלי מאומת.
- הבילדר מרנדר כרטיסים עם ספירה לאחור (ימים/שעות/דקות) שרצה בדפדפן, מועד בשעון ישראל, ותגית סטטוס. ממוקם אחרי לוח האירועים ולפני החדשות.
- **חי באתר**: `site/api/launches.js` (פונקציית Vercel) מביאה את 12 השיגורים הקרובים מ-LL2 עם קאש של 15 דקות. הדף מושך אותה (`data-api` = base_url + `/api/launches`), מעדכן מועד וסטטוס של הכרטיסים לפי `id`, ומחליף כרטיס שכבר שוגר בכרטיס "עדכון אוטומטי" של השיגור הבא. בארטיפקט ובקובץ המקומי ה-fetch נכשל בשקט והכרטיסים נשארים סטטיים.
- שורת הסטטיסטיקה ("נתוני השבוע") הוסרה לצמיתות באותו יום.

## כללי תוכן מחייבים

- **אפס המצאות**: כל אייטם עם URL מקור אמיתי שאומת; סטטיסטיקות מחושבות רק מהחומר שנאסף (לוג שיגורים, סכומי גיוסים, ספירת הזדמנויות). כתבות שנוספות ידנית מהמאגר — לאמת מחדש (סוכן אימות ייעודי).
- **עברית פשוטה, מסקרנת ומתומצתת** (הנחיית מאיה 17.8): כותרת עם וו, teaser משפט אחד, more 2–4 משפטים עובדתיים. בלי תיאורים מפוצצים.
- **דבר המערכת ללא חתימה אישית** — חתום "מערכת הניוזלטר" עד לאישור נוסח וחתימה רשמית (אין לייחס טקסט לאיתן סטיבה או לכל אדם אחר ללא אישור).
- הזדמנויות: רק כאלה שפתוחות אחרי תאריך הגיליון. דיווחי ספקולציה (כמו Decart–SpaceX) — לנסח כספקולציה עם ייחוס.
- תגיות סקופ: ישראל (כהה) / בינ״ל (בהיר); קטגוריות: מדיניות, ביטחון, שיגורים, כלכלה ותעשייה, חקר החלל (+חישה מרחוק/תקשורת לוויינית לפי הצורך).
- **תמונות כתבות**: og:image מהכתבה עצמה עם קרדיט בפוטר (הנחיית מאיה 17.8). לפני הפצה רחבה — לוודא זכויות שימוש (נאס״א/הודעות יח״צ בטוחות; צילומי מערכת של אתרי חדשות — באדיבות המקור המקושר).
- סרטונים: תמבן+קישור החוצה בלבד (CSP של Artifact חוסם iframe של יוטיוב); לאמת ID מול דף הצפייה.

## מגבלות ידועות

- לא מתאים להדבקה ישירה כגוף מייל ב-Outlook (flexbox/grid); לשליחה כמייל נדרשת גרסת טבלאות (לא נבנתה — החלטת מאיה 16.8.2026). ההפצה כרגע: קישור ל-Artifact או הקובץ המלא.
- לוגו הפורום (`assets/logo-isf.svg`) הגיע ריק מייצוא Claude Design — הבילדר מדלג עליו אוטומטית; החליפו בקובץ תקין והוא ישולב בטופבר.
- **אימות ויזואלי ב-Edge headless**: יש לו רוחב חלון מינימלי (~500px) — צילום "נייד" חייב `--window-size=500,...` ומעלה, אחרת הדף מרונדר ב-481px והצילום חותך את צד ימין (RTL). זה ארטיפקט צילום בלבד — הדף עצמו תקין בכל רוחב (אומת בכרום אמיתי).
